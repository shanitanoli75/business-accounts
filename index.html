How to use

Each account has separate subtabs and separate forms. Use Edit or Delete in the Actions column. Payments are recorded by date in their own tabs. This app stores records in this browser only; use Backup / Settings to export data before changing the software.

Important: uploading a new version to GitHub Pages does not transfer browser-local records to another device. Keep a backup before replacing the file.
